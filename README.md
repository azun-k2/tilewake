# Tilewake

Support pages and privacy policy for **Tilewake**, a sliding puzzle whose pictures wake up (iPhone, iPad, Mac, Android). Served by GitHub Pages at <https://azun-k2.github.io/tilewake/>.

Icons are regenerated from the app with `../_tools/make-site-icons.py` run in `../Tilewake`.
The store badges and the "More apps" grid are written by `../_tools/site-family.py apply`.
